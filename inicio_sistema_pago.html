Flujos de Compra Implementados

✓ Flujo 1: Pago con Tarjeta

1. Cliente va a carrito

Usuario selecciona "Finalizar Compra"

2. Selecciona método

Elige "Pago con Tarjeta"

3. Completa datos

Ingresa: nombre, número, vencimiento, CVV

4. Se guarda orden

BD: estado = "pendiente_pago_tarjeta"

5. Confirmación

Cliente ve número de orden

6. Admin confirma

Admin marca como "Pagado" en gestor

✓ Flujo 2: Pagar en Tienda

1. Cliente va a carrito

Usuario selecciona "Finalizar Compra"

2. Selecciona método

Elige "Pagar en Tienda"

3. Selecciona tienda

Elige sucursal cercana

4. Genera código

Sistema crea código de barras único (CODE128)

5. Se guarda orden

BD: estado = "pendiente_pago_tienda"

6. Muestra código

Cliente ve código de barras + instrucciones

7. Descarga/Imprime

Cliente descarga PNG o imprime comprobante

8. Paga en tienda

Cliente lleva código en 3 días hábiles

9. Admin confirma

Admin marca como "Pagado"

Base de Datos - 2 Tablas Creadas

Tabla: ordenes

  • idorden - ID único (auto-increment)
  • idusuario - ID del cliente
  • fecha_orden - Fecha y hora
  • total - Monto de compra
  • estado - pendiente_pago_tarjeta, pendiente_pago_tienda, pagado, cancelado
  • metodo_pago - "tarjeta" o "tienda"
  • numero_tarjeta - Últimos 4 dígitos (seguridad)
  • codigo_barras - Único CODE128
  • tienda_cercana - Nombre de sucursal
  • detalles_orden - JSON con productos

Tabla: detalles_orden

  • iddetalle - ID único
  • idorden - FK a ordenes
  • nombre_producto - Nombre producto
  • precio - Precio al comprar
  • cantidad - Cantidad comprada
  • subtotal - Precio x Cantidad

Características Principales

  • Pago con tarjeta con validación de CVV y vencimiento
  • Pago en tienda con código de barras CODE128
  • Código de barras único y descargable como PNG
  • Panel de administración con estadísticas
  • Filtrado de órdenes por estado
  • Modal con detalles de orden
  • Formulario con validación en cliente y servidor
  • Interfaz responsive (mobile-friendly)
  • Formato automático de tarjeta (espacios)
  • Almacenamiento seguro (solo últimos 4 dígitos)
  • Estados de orden actualizados
  • Índices en BD para búsquedas rápidas
