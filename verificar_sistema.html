Verificador del Sistema de Pago

Información: Esta página verifica que todos los archivos y tablas necesarias estén instalados correctamente.

Archivos del Sistema

Verifica que estos archivos existan en tu carpeta tiendaonline:

✓ metodos_pago.php - Página para seleccionar método de pago
✓ procesar_pago.php - Procesa la orden y genera código de barras
✓ confirmacion_pago.php - Muestra confirmación de compra con código de barras
✓ crear_tabla_ordenes.php - Ejecutar una vez para crear tablas en BD
✓ gestor_ordenes.php - Panel de administración de órdenes
✓ get_detalle_orden.php - Obtiene detalles de una orden
✓ schema_ordenes.sql - Script SQL para crear tablas manualmente

Tablas de Base de Datos

Tabla: ordenes

Campo Tipo Descripción
idorden INT AUTO_INCREMENT ID único de la orden
idusuario INT ID del cliente (0 si es anónimo)
fecha_orden TIMESTAMP Fecha y hora de la orden
total DECIMAL(10,2) Monto total de la compra
estado VARCHAR(50) pendiente_pago_tarjeta, pendiente_pago_tienda, pagado, cancelado
metodo_pago VARCHAR(50) tarjeta o tienda
numero_tarjeta VARCHAR(20) Últimos 4 dígitos de la tarjeta (seguridad)
nombre_tarjeta VARCHAR(100) Nombre titular de la tarjeta
fecha_vencimiento VARCHAR(10) MM/AA del vencimiento
codigo_barras VARCHAR(100) UNIQUE Código único para pago en tienda
tienda_cercana VARCHAR(100) Nombre de la tienda seleccionada
detalles_orden JSON Productos y cantidades en formato JSON
fecha_actualizacion TIMESTAMP Última modificación

Tabla: detalles_orden

Campo Tipo Descripción
iddetalle INT AUTO_INCREMENT ID único del detalle
idorden INT ID de la orden (FK)
idproducto INT ID del producto
nombre_producto VARCHAR(255) Nombre del producto
precio DECIMAL(10,2) Precio al momento de compra
cantidad INT Cantidad comprada
subtotal DECIMAL(10,2) Precio x Cantidad

Flujo de Compra

Paso a Paso:

  1. Cliente agrega productos al carrito (session['carrito'])
  2. Cliente hace clic en "Finalizar Compra" → va a metodos_pago.php
  3. Cliente selecciona método de pago
    • Opción A: Pago con tarjeta → Completa formulario
    • Opción B: Pagar en tienda → Selecciona tienda
  4. Click en "Procesar Compra" → POST a procesar_pago.php
  5. Sistema guarda orden en BD
    • Crea registro en tabla 'ordenes'
    • Crea registros en 'detalles_orden'
    • Si es tienda: Genera código de barras único
  6. Redirige a confirmación → confirmacion_pago.php
    • Si es tarjeta: Muestra número de orden
    • Si es tienda: Muestra código de barras + instrucciones
  7. Cliente ve y descarga/imprime
  8. Admin gestiona orden → gestor_ordenes.php
    • Ver detalles de orden
    • Ver código de barras
    • Marcar como pagada

Primeros Pasos

IMPORTANTE: Debes ejecutar el archivo de crear tablas PRIMERO, antes de probar el sistema.
  1. Crea las tablas en la BD
    Opción A (Automática): Haz clic aquí
    Opción B (Manual): Copia el contenido de schema_ordenes.sql en phpMyAdmin
  2. Verifica que no haya errores en la salida
  3. Prueba el sistema
    Ve a la tienda
    Agrega productos → Finalizar compra → Selecciona método de pago
  4. Accede al panel de admin
    Gestor de órdenes

Consideraciones de Seguridad

⚠️ ADVERTENCIA: Este es un sistema de demostración. Para PRODUCCIÓN, implementa las siguientes medidas:
  • SSL/HTTPS: Usa certificado SSL en producción
  • Encriptación: Encripta datos sensibles (tarjetas)
  • Pasarela de pago: Integra Stripe, PayPal o mercadoPago
  • Validación: Valida datos en servidor, no solo cliente
  • PCI DSS: Cumple con estándares de pago si manejas tarjetas
  • Logs: Registra todas las transacciones
  • Auditoría: Mantén historial de cambios en órdenes

Solución de Problemas

Error: "Table 'ordenes' doesn't exist"

→ Solución: Ejecuta crear_tabla_ordenes.php

Error: "undefined variable carrito"

→ Solución: Asegúrate que session_start() está en carrito.php antes que cualquier HTML

Código de barras no se visualiza

→ Solución: Verifica conexión a internet (JsBarcode se carga desde CDN)

Las órdenes no se guardan

→ Solución: Verifica los logs del servidor y errores SQL

No puedo ver el gestor de órdenes

→ Solución: Verifica permisos de carpeta y que la BD esté funcionando
